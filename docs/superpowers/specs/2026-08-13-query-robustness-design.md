# Устойчивость поиска к формулировкам

**Дата:** 2026-08-13
**Статус:** согласован
**Предшествующая спека:** [фильтрация и чистота выдачи](2026-08-13-search-refinement-design.md)

## 1. Проблема

Запрос «Re zero 1 сезон» не находит Re:Zero. Замер 2026-08-13:

| Запрос | Что вернули источники | Ранги строк | Итог |
|---|---|---|---|
| `Re zero 1 сезон` | animego 50, hdrezka 36, yummy 20, anilibria 5 | **все 100 — низший** | мусор в выдаче |
| `Re zero` | animego 27, hdrezka 6, yummy 20, anilibria 5 | 21 высокий, 27 низший | 21 строка Re:Zero |

Причина: релевантность работает по принципу «вся фраза целиком или ничего». Слов «1 сезон»
нет ни в одном названии, поэтому низший ранг получают все строки. Отсечение в такой
ситуации отключается намеренно (иначе пустой экран), сортировка откатывается к числу
источников — и наверх всплывает посторонее.

Дополнительно: уточнение в запросе портит выдачу **самих источников** — animego на
«Re zero 1 сезон» отдал 50 результатов вместо 27.

Третье, замеченное ранее: названия с hdrezka тащат служебные хвосты со страницы поиска —
«Жизнь по вызову 3 сезон, 10 серия», «Во все тяжкие Завершен (все серии)». Из-за них
одинаковые тайтлы с разных источников не склеиваются.

## 2. Цель

Находить нужное независимо от того, как пользователь дописал запрос.

## 3. Не-цели

- Не вводим нечёткое сравнение названий — оно склеивает разные тайтлы.
- Не показываем год выпуска: шум ради редкого случая.
- Не трогаем набор источников и воспроизведение.

## 4. Уточнения вырезаются из запроса

Из текста, уходящего в источники, убираются служебные уточнения:

- `N сезон`, `сезон N`, `N серия`, `серия N`, `N эпизод`;
- слова `смотреть`, `онлайн`, `бесплатно`, `hd`.

**Слова `сезон` и `серия` вырезаются только рядом с числом либо последним токеном при
наличии ещё минимум двух слов.** Иначе «Сезон охоты» превратился бы в «охоты».

Порядок разбора: сначала уточнения, потом тип контента. Тогда «жизнь по вызову сериал
1 сезон» даёт текст «жизнь по вызову» и фильтр «сериал».

## 5. Ранг по покрытию слов

Между «содержит фразу» и «нерелевантно» добавляется ступень: **все значимые слова запроса
встречаются в названии**, в любом порядке и вразбивку.

Значимые — не чисто цифровые. Замер показал, почему: по слову «1» в запросе матчится
«Take 1: с первого дубля 1 сезон, 7 серия».

Итоговая шкала (меньше — релевантнее):

| Ранг | Условие |
|---|---|
| 0 | название совпадает с запросом |
| 1 | название начинается с запроса |
| 2 | название содержит запрос |
| 3 | все значимые слова запроса есть в названии |
| 4 | остальное — отсекается |

Порог отсечения смещается с 3 на 4.

## 6. Служебные хвосты вырезаются из названий

`strip_service_info(title)` убирает по шаблонам: `N сезон`, `N серия`, `сезон N`, `серия N`,
`Завершен`, `Онгоинг`, `(все серии)`, `[все серии]`, осиротевшие запятые и лишние пробелы.

**Голые числа не трогаются** — «Наруто 2» это часть названия.

Применяется в двух местах:

- в `normalize_title`, поэтому «Жизнь по вызову 3 сезон» с hdrezka склеивается с «Жизнь по
  вызову» с другого источника;
- к отображаемому названию группы.

## 7. Тесты

Без сети:

- вырезание уточнений: `N сезон` в конце и середине, `сезон N`, `N серия`, шумовые слова,
  «Сезон охоты» не трогается, голое число не трогается;
- порядок разбора: уточнение и тип в одном запросе;
- ранг 3: все слова вразбивку и в другом порядке; цифровые слова не учитываются;
- отсечение: порог сместился, ранг 3 не отсекается;
- чистка хвостов: все шаблоны, «Наруто 2» не меняется, склейка после чистки.

С сетью:

- «Re zero 1 сезон» — первая строка содержит Re:Zero;
- «наруто 1 сезон» — выдача не пустая и релевантная.

## 8. Риски

| Риск | Митигация |
|---|---|
| «сезон»/«серия» в настоящем названии | Вырезаем только рядом с числом или в конце фразы; «Сезон охоты» покрыт тестом |
| Ранг 3 пропустит слишком много | Требуются **все** значимые слова, а не часть |
| Чистка хвостов испортит название | Только распознаваемые шаблоны, голые числа не трогаются |
